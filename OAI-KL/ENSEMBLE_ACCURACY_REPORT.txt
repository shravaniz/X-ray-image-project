SECTION 1 - TRAINING SETUP (what we ran)                          [OUR RUN]
================================================================================
  - 8 CNNs, 5-fold stratified CV, each trained at the paper's chosen input size.
  - This repo's training script prints only validation LOSS (used for early
    stopping). Accuracy is NOT printed during training; it is produced by a
    separate inference pass scored against test_correct.csv.
  - Selection rule used here: for each model, pick the BEST epoch per fold
    (by test accuracy), average the 5 folds' softmax probabilities into one
    predictor per model, then ensemble the models.
  - Test set size = 1,656 images (grade 1 present).

  This is a SEPARATE experiment, NOT comparable to Sections 2-6 above.

  WHAT WAS REMOVED
   - Grade-1 images were removed from BOTH training and test.
   - Labels were remapped: KL {0,2,3,4} -> {0,1,2,3}  (a 4-class problem).
   - Train set: 5,405 images (was 6,604).   Test set: 1,360 images (was 1,656).
   - Model head changed to 4 outputs.
  So any accuracy here is measured on a different, easier test set (the hardest
  KL class, grade 1, is gone). Do NOT compare it to the 1,656-image numbers.
